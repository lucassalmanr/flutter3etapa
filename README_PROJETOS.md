# Projetos separados

As três atividades estão organizadas em pastas independentes:

1. `atividade_estoque/` — login, usuários, produtos e SQLite no Chrome.
2. `atividade_filmes/` — MVVM, Provider, Service e SQLite.
3. `bugsresolver/` — Operação Resgate com os 12 bugs corrigidos e `LAUDO.md`.

Cada projeto possui seu próprio `pubspec.yaml`, plataformas Flutter, testes e instruções no `README.md`.

Os arquivos Flutter que permanecem diretamente na raiz são a cópia misturada anterior. Eles foram preservados para evitar apagar trabalho sem autorização; use as três pastas acima para execução e entrega.
