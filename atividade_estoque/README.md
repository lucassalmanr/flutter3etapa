# Controle de Estoque

Aplicativo Flutter Web com cadastro e login de usuários, controle de produtos e persistência SQLite.

```sh
flutter pub get
flutter run -d chrome --web-port=8080
```

Os arquivos `web/sqlite3.wasm` e `web/sqflite_sw.js` já acompanham o projeto. As operações INSERT, SELECT, UPDATE e DELETE são registradas no terminal.
